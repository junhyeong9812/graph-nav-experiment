# 변경 요청: 구매 적립 포인트 도입

## 배경

재구매를 유도하려고 구매 적립 혜택을 도입합니다. 마케팅팀과 합의한 정책은 아래와 같습니다.

## 요구사항

1. 주문한 상품이 **배송 완료로 처리되면** 구매자에게 포인트를 적립해 주세요.
   - 배송 완료는 운송장 조회로 확인되는 경우가 여럿입니다. 운영자가 송장을 바로 조회하는 경우와 주기적인 배송 상태 갱신으로 확인되는 경우 모두 적립돼야 합니다.
2. 적립액은 **주문 총액(할인·포인트 사용 전 금액)의 1%** 입니다. 1포인트 미만은 버립니다.
   - 예: 주문 총액 123,456원이면 1,234포인트
   - 계산 결과가 0포인트면 적립하지 않습니다.
3. 적립 포인트의 유효기간·상태는 **기존 포인트 적립과 같은 규칙**을 따릅니다.
4. 주문 하나에 적립은 **한 번만** 합니다.
5. 적립되면 구매자에게 **혜택 알림**을 보내 주세요.
   - 알림 문구에 적립된 포인트 수를 숫자로 넣어 주세요(예: "1234P" 또는 "1,234P").
6. 판매자에게는 적립하지 않습니다.
7. 적립은 배송 완료 처리와 함께 바로 반영돼야 합니다. 별도 배치나 메시지 큐를 거치지 않습니다.

## 지켜야 할 것

- 배송 완료 시 기존에 하던 처리(주문·판매 상태 변경, 구매자·판매자 알림 등)는 그대로 유지합니다.
- 기존 테스트는 모두 통과해야 합니다.
