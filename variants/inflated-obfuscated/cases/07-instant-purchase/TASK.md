# 질문: 즉시 구매는 어떻게 처리되나

구매자가 판매자가 올려 둔 판매 입찰 하나를 골라 "즉시 구매"를 요청한다. 배송지 ID, 창고 보관 여부, 결제 정보도 함께 보낸다.

이 요청이 서버에서 어떻게 처리되는지 코드를 읽고 답하라. 코드는 고치지 않는다.

1. 요청은 어느 API로 들어와 어떤 처리 단계를 거치나? 동기 처리인가, 비동기 처리인가? 응답으로 돌려주는 ID는 무엇의 ID인가?
2. 어떤 엔티티가 새로 만들어지고, 기존 엔티티의 상태는 어떤 순서로 바뀌나? 각 단계 직후의 상태 값을 적어라.
3. 결제 수단(카드, 계좌이체, 일반 결제)에 따라 결과가 어떻게 달라지나? 즉시 구매가 끝까지 성공하는지도 적어라. 결제 대행사가 카드 결제를 실패로 응답하면 어떻게 되나?
4. 누가 어떤 알림을 받나? 알림은 언제, 어떤 방식으로 전달되나?
5. 처리가 끝났을 때 주문의 최종 상태는 무엇인가? 구매자가 "창고 보관"을 선택한 경우 무엇이 달라지나?

주석이나 메서드 이름이 말하는 의도와 코드의 실제 동작이 다르면, 실제 동작을 답하라.

## 답 형식

저장소 루트에 `ANSWER.md`를 쓴다.

- 위 질문 번호별로 단계별 답을 쓴다.
- 각 단계에 근거를 `파일경로:줄`(예: `src/main/java/.../Foo.java:120`) 형식으로 붙인다. 근거 없는 주장은 점수를 받지 못한다.
