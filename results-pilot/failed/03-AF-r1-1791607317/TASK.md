# 구매 입찰 내역의 전체 건수가 실제 목록과 맞지 않음

## 증상 (고객센터 접수)

- 마이페이지 "구매 입찰 내역"에서 화면 아래의 전체 건수와 페이지 수가 실제로 넘겨 볼 수 있는 목록과 맞지 않는다.
- 예: 전체 5건, 3페이지(페이지당 2건)로 표시되는데 넘겨 보면 2페이지 중간에서 목록이 끝나고 3페이지는 비어 있다.
- 앱은 전체 건수를 믿고 다음 페이지를 계속 불러오기 때문에 빈 페이지 요청이 반복된다.
- 모든 고객에게 생기지는 않는다. 같은 고객이라도 입찰한 상품에 따라 생기기도 하고 안 생기기도 한다.

## 기대 동작

- 어느 페이지를 보든 전체 건수는 같아야 하고, 처음부터 끝까지 넘겨 본 항목 수와 같아야 한다.
- 지금 목록에 나오는 입찰은 계속 나와야 한다.
